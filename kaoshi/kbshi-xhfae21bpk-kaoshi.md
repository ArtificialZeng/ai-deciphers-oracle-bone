## 4. 義與競爭讀法（均未證實具體讀音）

### 4.1 領先結論：地名（田獵地／祈禱地；地方神名不能排除）

- 支持：(1) 正向診斷——「于 X 禱」全庫 14 例填充詞除殘字與另一未釋地名外皆為地名（岳／河／㘡／就／兇）；「X 京」之砓京／柚京／徹京／岫京／屰京皆為複合地名；「往于 X 獲」「往田从 X」之填充詞徹為確鑿地名；(2) 分布——8 例分處 H 祈禱卜辭 4 例與 HD 田獵卜辭 4 例，兩半語料皆為地名槽，地名之使用橫跨卜辭類別與貞人組，合於一處固定地點（田獵場／祭祀地）而非某人之專名（人名不橫跨于禱、京、往于獲三槽）；(3) HD288 S9／S10 同日平行對句（貞人子／巳）以同一地點占問田獵，合於固定田獵地之式。
- 地名 vs 地方神名：于岳禱／于河禱在商代既可解為「在岳／河之地祈禱」，亦可解為「向岳／河之神祈禱」，地名與地方神名在本字語料中無法區分，兩說並列，不作取捨。
- 未解：具體為何地（無任何地名可指）；H8040「__ 京」之複合地名全稱（京前一字即本字，京後殘失）；HD352「__ 南豕」之南界（X 之南多遠無從考）。

### 4.2 人名——已排除

- 反對：(1)「于 X 禱」之 X 若為人名，「在某人處祈禱」無平行（于之後接人名的禱辭無例；禱之賓語為神／地方，見 H30397 同片 S2「禱方」）；(2)「__ 京」之複合地名式不填人名（砓／柚／徹／岫／屰皆地名）；(3)「往于 X 獲」之 X 若為人名，「前往某人處捕獲」不成句（往于之後必為地點）；(4)「从 X 西」之 X 若為偕行者，須與于禱、京二槽同解，人名說不能覆蓋全部 8 例。

### 4.3 動詞——已排除

- 反對：(1)「于 X 禱」之 X 夾於介詞于與動詞禱之間，必為名詞性成分，動詞說句法不成立；(2)「__ 京」無動詞＋京之式；(3)「往于 X 獲」之 X 若為動詞，「往于＋動詞＋獲」無平行。8 例中無一例居動詞診斷槽（如弗／勿之後、賓語之前）。

### 4.4 祭品／獵物名詞——已排除

- 反對：(1)「往于 X 獲」之 X 若為獵物，「前往獵物處」不成句（獵物為獲之賓語，不為往于之賓語）；(2)「于 X 禱」之 X 若為祭品，「在祭品處祈禱」無平行（禱之祭品居禱之後，如「禱禾」「禱牛」，不居于禱之間）；(3)「__ 京」不填祭品名。

### 4.5 植物名（通詞名詞）

- 支持：字形兩部件皆近植物（櫛齒如枝刺、葉形如葉／種子），地名多取自植物（柚、棘、桑皆植物得名之地），本字所指之地或以某植物得名。
- 反對（作為詞類）：8 例中無一居通詞名詞槽；禱之後可填名詞（禾 66 例）而本字僅 1 例居禱後且為句末殘句（H29991），不能立通詞名詞說。結論：**字形或為植物象形，詞為地名**——形義分屬兩層，不矛盾，亦不構成讀音。

### 4.6 已釋字異寫

- 斤／棘／來／禾／束／𣎳／桑／目／朿／岳／河／㘡／柚／徹／岫／屰／砓／就／兇／京皆已逐部排除（§2.2）；爪／瓜／困／𣏔未比對，留待後查（但四字皆非地名槽字，即便形合亦須另解槽位）。

### 4.7 合文

- 無分解依據、無分寫平行句。0bcpbg0geh 案有禍／尤逐筆對應與互補分布為憑，本字兩部件皆無已知讀音，無此類證據，不予採納。

### 4.8 形義關係

字形植物狀（櫛齒＋葉）指植物，語槽指地名——與 fi、xdi、qw5、diesgffg1o 輪同類張力，處理一致：**語槽勝**。地名多以植物得名（柚、桑、棘），形義張力在此案中弱於前數輪（植物形＋地名槽並無衝突，植物很可能正是得名之由）。
