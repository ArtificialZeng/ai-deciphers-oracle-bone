## 3. 音

- 若合文說成立，本字無需新音：讀作兩個已知詞 **禍（OC *ɡʷaːlʔ，huò）+ 尤（OC *ɢʷə，yóu）**，即「禍尤」。音環以「不設新詞」的方式閉合，這是合文說相對「新字說」的優勢。
- 但須誠實記錄一個懸案：**左部 𡆥 字的現代讀法本身有爭議**。OBIMD 將其隸定為禍；另有學者讀為憂（如俄文研究 "旬亡憂"：Heji 6057「癸巳卜，𣪊貞：旬亡𡆥？王占曰：㞢求，其㞢來艱」，其中 𡆥 有人讀憂）。若左部實為憂，則本字為「憂尤」合文。**不論左部讀禍或憂，語義結論不變**（皆為旬卜所否定的災異名詞），僅第一詞的現代讀音待定。本筆記寫「禍尤」時取 OBIMD 的隸定，附此注。

## 4. 義與用

- **語義**：「旬亡禍尤」=「此旬之中既無禍、亦無尤」，即對兩種災異的並列否定。旬卜例行否定一組災異名詞，禍、尤、災三字皆見於同一語槽：
- 亡之後的 token 全庫統計：禍 519、尤 397、348、**本字 96**、災 50（為殘損字，餘為他字）。
- 「亡禍才……」式亦見於禍本身（如 H20598、H24315、H25581、H25634、H25673「亡才九月/四月」），故本字後接「才 + 月/夕數」與禍的句式完全一致。
- **分佈互補**：55 片含本字的拓片中，僅 1 片同時含禍，**0 片含尤**——本字與禍、尤在同一卜辭群內近乎互補分佈。若本字是第四個獨立災異詞，應與禍、尤隨機共現；若為禍尤合文，則同一卜辭群內用合文即不用分寫，互補正是預期的分佈。
- **協調讀法的平行證據缺失**（誠實記錄）：全庫中「禍 + 尤」作為兩個獨立 token 相鄰出現者為 **0 例**。合文說因此缺少「亡禍尤」分寫的獨立平行句。這是合文說目前最弱的一環：它預測「旬亡禍尤」是一個可說的命辭，但語料中從未見其分寫形式。反過來說，分寫為零亦與「此卜辭群習慣以合文寫此二字」相容，但不能由此證明習慣存在。

## 5. 競爭讀法

| 編號 | 讀法 | 評價 |
|---|---|---|
| **A（首選）** | **禍尤合文**：左右並寫的兩個災異詞 | 形（逐筆分解）、槽（旬亡公式）、分佈（與禍/尤互補）三者一致；無需新音新義 |

| C | 獨立的第四個災異名詞 | 字形上最難成立：一個新詞的字形恰好等於兩個已知災異詞的並置，概率極低 |

| E | 尤的加框異寫：框為尤的義符 | 框並非尤的偏旁，禍字有框而尤字無框，方向反了；排除 |
