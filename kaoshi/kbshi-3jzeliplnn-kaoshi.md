## 4. 義與競爭讀法（均未證實具體讀音為已解）

### 4.1 領先（採納為正面結論之具體讀法，未證實）：剌（là）人名

- 支持：(1) 字形三部皆合——甲部為禾（分叉頂＋直莖），甲部莖中菱形環為口（CUHK 剌條：「『禾』中間有『口』形（『口』是指示符號，指示禾的稈部），是『𥞥』的初文（裘錫圭），表示禾稈，亦作為『剌』的聲符」；「甲骨文從『禾』從『口』從『刀』，象用刀割除禾稈之形，本義是割禾（參季旭昇）」），乙部為刀（閉合葉形＋折線足，卲式刀部為旁證，見 §2.2）；《說文》亦稱剌「从束从刀」（束即禾＋口之合）；(2) 用法相合——CUHK 剌條明言「**甲骨文用作人名**」；(3) 槽位相合——人名為唯一與 7 例皆相容之詞類（見 §1.3）；(4) 互補分布——OBIMD 剌字頭（UID `57dttn2mfe`）零 token，平臺未將任何 token 歸入剌，而本字 7 例為庫內唯一禾＋口＋刀形之未釋字；(5) 刀字族用作人名有先例（CUHK 刀部件頁：刜「又用作人名」見《合集》22247、剛「又用作人名」、絕「甲骨文用作人名」）。
- 反對（未推翻，然須回答）：(a) CUHK 三枚甲骨字例之圖像未能取回——其甲骨字例圖像端點（oracle.php）前輪已證返回空回應，本輪所取頁面不含圖像 URL；其合集號未知，未能與本字 7 例逐枚比對；(b) 橫杠（pyrv 6/6）於禾＋口＋刀三部無位——或為口之異寫、或為第四部件，未決；(c) CUHK 計 3 例、本字 7 例——若 CUHK 三例為合集片而本字 7 例皆為花東片，兩組是否同字須以圖像核驗（花東片未入《合集》释文 OCR，見 §4.7）；(d) 刀之閉合葉形寫法僅見卲一字（7 例）為旁證，利／刜／剛之刀皆為單曲筆，乙部＝刀之認定為推論而非定論。
- 結論：剌為最可能之讀法，然未證實；人名結論（§4.2）不依賴剌說。

### 4.2 人名說——已決（詞類結論）

- 內容：本字為一人名（或族名／貞人名），具體所指不可恢復；最可能為剌（見 §4.1），然剌說證偽亦不動搖人名結論。
- 支持：排除法——人名為唯一與全部 7 例皆相容之詞類（見 §1.3）；正向平行例：宜 X 牝之丁（人名）、往 X 之𫹉（人名，H5088「王往𫹉」）、眔（人名，乎／取／戎／令諸槽）、X 貞之殻／賓／爭／亘／行／史（皆為貞人名）。
- 族名並列之理由：商代人名與族氏名常難分（如𫻨之地名與族氏難分，見 2bc 輪），本字所指之人或即以剌（割禾）為氏之族人；人名與族名在此無法區分，並列為同一結論的子類。
- 結論：詞類已決為人名，故**放棄作通詞考釋**；具體人名（剌與否）、讀音、所指人物皆未證實（見 §5）。

### 4.3 動詞說（割禾／切割類）——已排除為主說

- 內容：若本字為動詞（剌之本義「割禾」，或泛言切割），則「宜 __ 牝」讀「宜割牝」（宜割一牝牲）、「往 __」讀「往割」（往而割禾）、「眔 __」讀「眔割」（眔行割事）、「乎 __」讀「召而割」。

### 4.4 地名說——已排除

- 內容：若本字為地名，則「往 __」讀往［地］、「眔 __」讀發眔往［地］。
- 排除理由：(1) 乎 __ 槽：乎召人／動詞，不召地名；(2) 刵 __ 于［tq26］槽：__ 後已有處所補語于 tq26（確鑿地名），雙處所不合；(3) __ 貞槽與宜 __ 牝槽（丁）皆不取地名；(4) 在／于／自／往之地名診斷槽皆為 0 例（本字從不在在／于／自之後，往後 1 例亦為往 X 槽而非往于 X 槽）。排除。

### 4.5 動物／祭品名說——已排除

### 4.6 束／利／刈說——皆已排除，僅為部件旁證

- 束（木＋口）：甲部之環與束逐筆相合，然束無乙部、無橫杠，另有字頭（5 例）。排除為全字，僅為甲部平行例。
