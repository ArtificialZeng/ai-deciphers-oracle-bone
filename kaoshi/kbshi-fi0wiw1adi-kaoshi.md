# 考释笔记：甲骨文 OBIMD UID fi0wiw1adi（花东歲祭中的白色可数祭品，未释）

**结论先行：存疑。** 这是一个真实存在的未释字：用例与语槽全部可核查，
不是人名/地名，也不是动词；但形、音两环都立不起来，提不出可证伪的读音与释义。
**本笔记不拟读。** 它是转录侧筛查的 #2 候选，不是因为它快被破解了，
而是因为它的语槽比 #1 更窄（只出在歲/祭句里），且“白 + __”两例把它
钉在了一个很具体的祭品槽位上——同时它的字形却没有动物的任何特征，
这是本字最诚实、最值得记录的张力。

**标识。** 本笔记用 OBIMD（*Scientific Data* 2026, DOI 10.1038/s41597-026-06967-0）

U+F1F87，无标准汉字对应。**本笔记不给该字造一个汉字写法，也不拟读。**
字形描述见 §2，标准字形图见 OBIMD `subchar-images.zip` 中该 UID 的 1 张标准字形图

### 对短名单 slot 描述的订正（重要）

短名单称本字语槽为“歲/祭 + 先祖 + + 一/三”，**这个表述过紧了，
与 13 句逐一核对后不成立**，订正如下：

- 后一字为“一”者 9 例（HD215、HD241、HD261×2、HD267、HD296 S8、HD394、
HD427×2）；但 HD142 后接“又”，HD274 后接另一未释字（𠯑），HD463 后接“才”，
HD296 S2 居句末、后无字。
- 前一字为先祖名者仅约半数：妣庚 3、妣甲 1、妣丁 1、妣己 1、祖乙 1；
其余为白 2、一 1（HD215，前有另一未释字 + 一）、子 1（HD241）、庚 1（HD296 S2，
“歲匕庚”之“庚”为妣庚的省称）。
- 数词“三”只出现 1 次（HD463），且在**本字之前**（“歲祖乙三才”），
不是之后。
- **修正后的语槽**：本字恒出于歲祭（12 例）或祭（1 例）句中，
位于“歲/祭 + 先祖名”之后、一个祭品序列之内，通常（9/13）后接数词“一”，
两次前接“白”。它是一个**可计数的祭品名词**，不是动词、不是专名。
句式与花东歲祭的通式 `[歲-祖妣名-祭品]`（KCI 2012，见 §4.2）一致。

## 2. 字形分析（形）

- **结构（单式，13 例摹本皆同构，见 `crop_fi_all13.png`）。** 可拆为四部分，
全部附于一根右竖干上：
- 上：两斜笔自左上交叉竖干，形成一个“X”/“乂”形顶；
- 中：左下侧一小闭合三角，尖端触竖干、底边朝左（HD261、HD274 最清晰；
HD142、HD394 中该三角较开放、近于弧笔，属同字异笔，非另一字）；
- 下：一长斜笔自竖干下部扫向左下，末端超出竖干底部；
- 竖干本身直达底部，无横底、无足。
- **没有的构件（同样重要）。** 无头、无角、无耳、无足、无尾、无口、无器皿
的口沿与底座、无横杆。也就是说：字形中没有任何一个可辨认的动物构件，
也没有任何器皿构件。
- **最自然的读法。** 一根带分枝的茎/干，左侧带一叶状或果实状三角——
植物（茎、禾类、柴束）一类的象形。这是“像”，不是结论；见 §5B 的
反对意见。
- **已排除的邻字（逐一比对 OBIMD 标准字形图，非凭印象；本轮新做，
不采信上一轮的结论）。**
- 动物：豕（侧视立猪，有吻、身、腿；中式有三角身但带吻与腿）、
豭（豕 + 生殖器竖画）、牛（双角在上 + 竖干 + 下箭）、羊（双角正面羊头）、
犬（头 + 身 + 弯尾；中式带方格身）、馬（头 + 鬃 + 腿）、鹿（鹿角 + 横身 + 腿）、
兔（长耳 + 曲身）、虎（头 + 纹身 + 尾）、象（垂鼻 + 身 + 腿）、
彖/彘（豕 + 矢/吻部横笔）、䝅（豕 + 丄，雄性标记）、牡（牛 + 土）、
牝（牛 + 匕）、廌（角 + 身 + 腿）、戓（“十”字 + 小方框）。
**无一与本字形合**：本字无吻、无角、无腿、无尾。
- 植物/谷物：禾（竖干 + 顶叉 + 中叉，无闭合三角，干直达底部成足）、
來（双侧分枝 + 双足，左右对称；本字仅左侧分枝、单斜笔到底）、
麥（顶叉 + 波状下茎）、黍（多穗点 + 分枝）、芻（双小叉 + 弯干）、
米（六短竖 + 横杠）、束（竖干 + 2–3 个对称叠置菱形）、木（顶叉 + 底叉，
无三角）、桑/林（多木）。
- 器皿/酒器：尊（口沿 + 尖腹 + 双叉足）、爵（口 + 方腹 + 三足）、
彝（盖 + 腹 + 足）、鬯（交叉纹器身 + 勺）、㿝（方口 + 三足）、匁（波状竖 + 短斜笔）。
- 兵器/工具：戈（单横 + 竖 + 钩，无三角）、矢（箭头 + 横杠 + 菱形镞身）。
- **与本字骨架最接近的是豕/豭/犬与禾/來**（竖干 + 顶斜笔 + 中部构件 +
底部斜笔），但每一组都有诊断性差异：豕/豭/犬有吻或尾或方格身；
禾无闭合三角且干成足；來双侧对称且双足。**现有材料下排除，
但这是本笔记最怕的翻案点：只要《新甲骨文编》查到同形已释字，全盘推翻。**
- **摹本裁图的伪影（已排除，不属字形）。** HD142 右下、HD394 右侧、
HD463 右侧的竖笔为相邻列字符的笔画，不在本字的 OBIMD 定位框内；
HD267 字形上方的小圆圈为上一行字符的残笔。判断依据：OBIMD `Position`
定位框（HD142 为 50×90 等）与标准字形图（单式）一致。

## 4. 义与句法检验（义、用）

### 4.1 语槽统计（OBIMD 全库，本地统计）

- 前一字：妣庚 3、白 2、妣甲 1、妣丁 1、妣己 1、祖乙 1、庚 1、一 1、子 1。
- 后一字：一 9、又 1、𠯑（bor1nhz1d4）1、才 1、句末 1。
- **祭品槽的直接证据。** 花东子集内“歲 + 先祖名 + 1”位置的词库存量：
牢 13、㛸 13、牡 9、牝 8、豭 7、小 7、白 5、彖 4、廌 3、䝅 3、豕 3、羊 1、
豖 1，另有未释 PUA 字 \U000bdc20 14 例、\U000bdc1f 5 例。
本字与牢/牛/牡/豭/羊等并列同一槽位；其中牢、牡、牝、豭、豕、羊皆为
牲畜或泛指祭牲。**本字在句法上就是一个祭品名词。**
- **数量词。** 后接“一”9 例，前接“三”1 例（HD463），余 3 例无数词
（HD142“又鬯一”之“一”属鬯，HD274 后接𠯑，HD296 S2 句末）。
“一”是最常见的祭品计数，牲畜、酒、玉皆可数一，不能由“一”定物种。
- **“白”的两例。** HD142 `白`、HD267 `友白一`。
OBIMD 全库“白”后所跟之词：豕 11、豭 10、<?> 9、戓 4、彖 3、牡 3、
牛 2、羊 2、一 2、屯 2、䝅 2、人 1、豖 1、黍 1、于 1（共 63 例）。
花东子集内“白”句另有：白豕、白豭、白彖、白䝅、白牛、白戓、白圭（玉）、
白屯。**“白”后多为牲畜，但也有玉器（白圭，HD193）与屯（HD220），
故“白”只能证明本字是“可加颜色修饰的祭品名词”，不能证明它是动物。**
上一轮短名单“最可能是白色牲畜之一种”的表述**过强**，本笔记订正为：
牲畜为首选假说，但玉器、谷物等亦未排除（见 §5）。

### 4.2 最有力的平行：Schwartz 的歲祭句式与“白豭一 鬯一”

Schwartz《Shang Sacrificial Animals》（*Animals Through Chinese History*,
Cambridge UP）引花东歲祭句，句式为：日期 + 歲（读为劌“斩切”）+ 先祖名 +
牲畜种类，并指出花东祭祀“讲究白色用牲、并按先祖性别配牲畜性别”。
其例（1）：`甲寅歲祖甲白豭一 鬯一登自西祭一`——“甲寅日歲祭祖甲，
白公猪一头，鬯酒一（份）”。与本字用例逐项平行：

| | Schwartz 例（1） | HD142（本字） | HD267（本字） |
|---|---|---|---|
| 歲祭对象 | 祖甲 | 祖乙 | 妣庚 |
| 白色祭品 | 白豭一 | 白 | 白一 |
| 随后酒品 | 鬯一 | 又鬯一 | （无） |

**语槽上，本字最像一个白色牲畜。** 但这只是语槽平行，不是字形证据；
字形一节（§2）恰恰不支持动物说。两环的张力如实记录，不强行调和。

### 4.3 句法疑点

- 若本字是动物名，则 HD241 `癸丑歲癸子一` 须把“癸子”解作
“歲癸、子（进献）一”，即“子”为进献者；HD274 `歲妣庚𠯑祖乙翼`
则后接𠯑 + 祖乙翼，祭品序列未以数词收束——两例都不干净，但都不致命。
- 若本字是植物/谷物，则 HD142“二牢、匁牛、白、又鬯一”的并列中，
植物与牲畜、酒并列亦常见（花东祭品分人牲、动物、酒、玉、绢、谷物六类，
KCI 2014 祭品论文），句法上同样可通。
- **分布窄。** 13 例全在花东子卜辞，无一例出自王卜辞（合集 9,913 条记录中
0 例）。若本字是常用牲畜名，王卜辞歲祭中理应出现——它的缺席有三种
可能：（a）它是子卜辞特有的词或写法；（b）它是稀有牲畜；
（c）OBIMD 只收《合集》的一部分（10,077 条记录），王卜辞中的同字
未被收录。**（c）使“缺席”只能作弱证据，不可作定论。**

### 4.4 传世文献：无对应

无任何传世文献词条可与一“歲祖妣白 __ 一”的字对上。《说文》无此形。
金文无后代。

## 5. 竞争性读法（必须逐一排除，现有材料排除不了）

### 竞争解释 A（本笔记首选，仍只是假说）：白色牲畜之一种（物种未定）

- 支持：祭品槽（§4.1）；“白”两例与全库“白 + 牲畜”的搭配习惯；
Schwartz 的歲祭句式与“白豭一 鬯一”平行；花东歲祭“牺牲偏重猪牛，
分类极细，讲究颜色与性别”（KCI 2012 摘要）。
- 反对：字形无任何动物构件（无头、角、足、尾、身）；13 例全在花东，
王卜辞无例；物种无法指定——猪、牛、羊、犬、鹿皆已排除形合，
剩下的只能是“某种未见于他处的牲畜”，这本身就是弱解释。
**未证实，勿作结论。**

### 竞争解释 B：植物性祭品（谷物、茅草、柴束一类）

- 支持：字形最自然的读法就是带分枝的茎（§2）；中部小三角可读作穗/叶；
花东祭品含谷物一类；“白”后亦有黍一例（全库 1 例），植物可加颜色修饰。
- 反对：花东歲祭祭品以猪牛为主，谷物极少出现在“歲 + 先祖 + __ + 一”
的槽位；“白”修饰植物在全库仅黍一例，远弱于牲畜；无任何一种已知
谷物/植物字（禾、黍、麥、芻、米、束、木）与本字形合。
**弱于 A，但未排除——字形一环上 B 其实强于 A。**

### 竞争解释 C：某已释字的花东异写（X/1850 式）

- 支持：花东书手写法特殊，未并入的异写真实存在（X/1850 = 由的异体）；
本字骨架与豕/豭/犬、禾/來共享“竖干 + 顶斜笔 + 中部构件 + 底部斜笔”。
- 反对：已系统比对 30 余邻字，每一组皆有诊断性差异（§2）；
本字 13 例字形稳定、单式，不似偶然简写。
**现有材料下排除，但这是最怕的翻案点。**

### 竞争解释 D：器皿/酒器之一种

- 支持：可计数（“一”）；常与鬯并列；器皿亦可加颜色修饰（白圭为玉器例）。
- 反对：无口沿、无腹、无足；尊/爵/彝/鬯/㿝皆形不合。
**基本排除。**

### 竞争解释 E：人名/专名

- 支持：无。本字从不出现于“令 __ 取/往”“往/于/自 + __”的人名/地点槽
（对照 2lep30tiiz 的使役人名句式与 tq26tb9tj9 的地点槽）。
**排除。**

### 竞争解释 F：动词
