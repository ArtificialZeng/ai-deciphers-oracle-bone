# 考释笔记：甲骨文 OBIMD UID gx21ndp7yy（“王 __ 叀吉”之字，未释）

**结论先行：存疑。** 这是一个真实存在的未释字，不是已释字的异写（现有材料下），
也不是人名/地名；但形、音两环都立不起来，提不出可证伪的读音与释义。

## 2. 字形分析（形）

- **结构（三式，见标准字形图与摹本裁图）。** 三个标准字形均为左右对称的
正面图形，可拆为上中下三段：
- 上：一“∧”形（倒 V）屋顶状笔画，顶点带一短竖尖（似箭头/尖顶）；
- 中：一三角形或梯形躯干，两侧斜边向下外张（第 3 式两斜边张成大三角翼形）；
- 下：两足（V 形两竖）。
摹本（合集 5250、5252–5257）与标准字形一致：屋顶 + 三角身 + 两足，
无一例外的附加笔画。字形稳定，不似两个字的合写。
- **象什么。** 最自然的读法是一个正面直立的形象：尖顶 + 张开的双翼/双臂 +
双足——鸟（正面、展翅、带冠）或人（戴尖帽、着三角袍）或帐篷/ hut。
三者都只是“像”，无一能由字形单独确立。
- **已排除的邻字（逐一比对 OBIMD 标准字形图，非凭印象）。**
來（70 式：中竖 + 两下垂枝 + 两足，无闭合三角身、无顶尖）；禾（Y 顶，
无足）；麥（波状中茎）；安（闭合屋形内含跪人，与本字“顶在外、身在下”
相反）；女（跪姿、波状下摆）；舞（顶横杆 + 指状垂手）；夢（卧人 + 目）；
射（弓 + 矢，58 式皆带弓弧）；侯（横杆下的人 + 矢）；矢（箭 + 横杠）；
鳳/隹/鳥（皆侧面鸟，头尾分明）；燕（细棍人形）；羽（双羽）；宜（尖顶
且形）；宗/家/室（屋顶 + 内部构件，结构不同）。**本字不是上述任何一字的
异写，至少在 OBIMD 的字形归并口径下不是。**
- **但留一手。** X/1850 的教训是：平台未归并的异写真实存在（X/1850 = 由的
未并入异体）。本字与 來/安 在“中竖 + 两足”的骨架上有远亲关系，不能
100% 排除它是某个已释字在武丁期鼎组卜辞中的特殊写法；排除它的证据是
字形差异（闭合三角身、顶尖）与共现（本字与 來在不同句中各行其是，未见
同句混用可资对照）——都是旁证，不是定论。

## 4. 义与句法检验（义、用）

### 4.1 语槽（全库统计）

- 前一字：王 16、<?> 11、𐌢形字（PUA）4、𖿻形字 3、徵 3、鼎 2、匁 2、臣 2。
- 后一字：叀 22、<?> 10、句末 7、用 5、見 4、不 2。
- **主导公式（合集块，约 30 例）：`鼎王叀吉`**，间或后接 `不冓雨`
（H5250、H30528）。“王 + X + 叀 + 吉”：王是主语，叀为前置宾语焦点标记，
吉为占问词。X 处在“王 ___ 惠吉”的动词/名词槽。
- **花东块（约 12 例）公式不同**：`乎徵見用`、`見用`、`受丁`、
`若`、`昃用`、`子乎多臣見用不率`。X 后接見/用/受/若/昃，
皆为动词或动词性成分；X 前为乎徵/子/多臣/王。

### 4.2 最有力的平行：王夢叀吉

“王夢叀吉”是卜辞常见句式（王之梦，惠吉乎？）。本字的合集块公式与之
逐字平行：王 + [王所经历之物] + 叀吉。夢之后亦常见“見”（夢見）。本字
在花东块后接“見”4 例，与“夢見”的搭配习惯相合。**语槽上，本字最像一个
“王所见/所经历之物”，占问其吉凶。**

### 4.3 句法疑点

- 若 X 是动词（“王行 X，惠吉？”），合集块可通，但花东块“乎徵見”
难通：乎徵（呼徵）之后直接跟动词 X 再跟見，两动连用无主语，不合卜辞习惯。
- 若 X 是名词（“王之 X，惠吉？”），两块皆通：合集块“王之 X 惠吉乎”，
花东块“見（X 出现）、用（用 X 占/用 X 祭）”。
- “昃用”（HD475）：昃为日昃（午后）时间词；“大亦昃用”以 X 为
名词读作“大亦 [行] X，昃，用 [之]”尚可，以动词读则“X 昃”不通。
**综合两块，名词说优于动词说。**

### 4.4 传世文献：无对应

无任何传世文献词条可与一“王 __ 惠吉、__ 見、__ 用”的字对上。
《说文》无此形。金文无后代。

## 5. 竞争性读法（必须逐一排除，现有材料排除不了）

### 竞争解释 A（本笔记首选，仍只是假说）：X 是一个“兆物/兆象”名词——王所见之异象或兆物

- 内容：鸟形兆物（正面展翅带冠之鸟）、或泛指一种出现后用以占卜的异象。
王有此兆，问吉凶；兆“見”（出现）、“用”（用以占验）。
- 支持：语槽（§4.2、§4.3）；字形为正面有翼形象，与“見/出现”相配。
- 反对：字形与一切已知鸟字（鳳/隹/鳥/燕）皆不同；若真是鸟，为何另造一字？
“用”的宾语在卜辞中多为具体祭品/工具，兆物“用”无确切平行。
**未证实，勿作结论。**

### 竞争解释 B：X 是一个动词（王所行之事）

- 支持：合集块“王 X 叀吉”可读作“王行 X，惠吉？”；“用”可读作动词 + 用。
- 反对：花东块“乎徵見”与“昃”难通（§4.3）；字形为具体形象，
非动作会意。**弱于 A，但未排除。**

### 竞争解释 C：X 是人名/官名

- 支持：王后常跟人名；“乎徵”可读作呼某人。
- 反对：人名在卜辞中多有“令 X 取/往/伐”等使役句式，本字 54 例中无一例
“令/乎取/往”式；与本字同类的 2lep30tiiz（71 例）恰恰充满
此类句式，对照之下本字不像人名。**基本排除，但非铁证。**

### 竞争解释 D：X 是某已释字的未并入异写（X/1850 式）

- 支持：平台归并“仅供参考”，武丁期一字多形常见。
- 反对：已系统比对最邻近的 20 余字，无一形合（§2）。**现有材料下排除，
但这是本笔记最怕的翻案点：只要《新甲骨文编》查到同形已释字，全盘推翻。**

### 竞争解释 E：X 是地名

- 支持：无。X 从不出现于“往/于/自/至 + X”的地点槽（对照 tq26tb9tj9
“才/于/往 + X”即地名）。**排除。**
