## 4. 争议字重读边界：勿误标为“AI 首次破译新字”

- **AlphaOracle（2026）《屯南》307 `勞`**：
  - 准确性质：**争议字新释／重读（disputed-graph re-reading）**，并非从零破译的全新未释单字。
  - 学术状态：该读法获宋镇豪先生肯定，并被「殷契文渊」平台采纳重标；但依古文字学与奖励计划口径，必须严格区分「争议字重读（二等奖范畴）」与「未释字首次破译（一等奖范畴）」，切勿混为一谈。

## 5. 语义／功能槽位已决字（勿当作“语义未知新词”或强造合文）

下列高频字在商代卜辞中的**词义或制度槽位早已明确**，仅在具体对应现代汉字或造字本源上仍有学术分歧：

1. **`旬亡□`（`禍／憂` 及其第五期黄组繁化单字异体，OBIMD `0bcpbg0geh`）**：
   - 语境义（旬卜灾异单字名词）与句式早已完全确立；《合集》35399、35401、35530 刊布释文一律隶作单字「禍／憂」，绝非「禍尤」双词合文（详见 `kaoshi/kbshi-0bcpbg0geh-kaoshi.md` Gemini 附记）。
   - **编码陷阱**：电子文献常用的 **`𡆥`（`U+211A5`）** 实为 5 画日本「図書館」略字（`囗+ト`），系当代排版借码充作甲骨字形代符，并非古代汉字。
2. **北方风名（四方风名系列）**：
   - 四方风之方位、祭祀语境与语义范畴早已完全确定，仅北方风名对应今字隶读仍有不同意见。
3. **周祭第四祀 `洅`（传统隶作 `洅`/`𣫭`/`載`，OBIMD `ff8rp0nh6u`）**：
   - 在晚商周祭五祀（`彡、翌、祭、洅、劦`）中的祭名槽位与跨代祀序已 100% 确定（同片中 `匸丙` = 先公 `報丙`）；唯造字本源与对应现代汉字仍存争议，保留作字源考证而非未知词类靶标（详见 `kaoshi/kbshi-ff8rp0nh6u-kaoshi.md` Gemini 附记）。

## 6. 高发 Unicode 编码与排印陷阱清单（检索与引证必查）

| 常见误码／代用码 | 真实目标／辨析 | 陷阱说明 |
|---|---|---|
| **`𠩺`（`U+20A7A`）** | **`≠ 𦀓`（`U+26013`，`⿰糹辛`）** | 武丁宾组兆语「不𦀓鼄」之第二字构形为 `⿰糹辛`（《说文》籀文繒 `𦀓`）；虽有论文标题权用「不𠩺蛛」，编码与字形不可混淆 |
| **`𩚑`（`U+29691`）／`𣲣`（`U+23CA3`）** | **`≠ 洅`（`U+6D05`）／`𣫭`（`U+23AED`）／`載`** | 周祭第四祀传统隶定为 `洅`／`𣫭`／`載`，切勿混用外观相近的误码 `𩚑`／`𣲣` |
| **`𪊓`（`U+2A293`，IDS `⿸鹿文`）** | **`≠` 原拓精确结构 `⿱鹿文`** | 《合集》36481 小臣墙刻辞 `白[⿱鹿文]` 电子排版权借半包围码 `𪊓`，务必显明区分 `⿱鹿文` 与 `⿸鹿文` |
| **`𡆥`（`U+211A5`）** | **日制 5 画略字（`囗+ト`，「図書館」略字）** | 仅作当代电子转写代符，不可当作先秦本字或查《说文》依据 |
| **`𰇑`（`U+301D1`，CJK Ext G）** | **`= ⿱册口` = 《说文》`𣆑`（`U+23191`）／`冊`** | Unihan 缺 `kMandarin` 不等于「无音义形码」；CJK 扩展 B–H 区须同步查 `zi.tools`、IDS 与古文字工具书 |
| **OBIMD 内部码位分叉** | `crck62eltz`（`U+AC71C` vs 合并 token `U+A713E`）；`0bcpbg0geh`（`U+B6AF4` vs `ff8` 附录 `𫴒` `U+2BD12`） | 跨轮引用 OBIMD token 时须同时核对 UID、`codepoint` 与摹本原图，不可仅凭单次输出码位判定同异 |
